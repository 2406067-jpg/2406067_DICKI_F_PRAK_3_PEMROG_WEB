## 📌 Pengenalan Proyek

Proyek ini dibuat untuk memenuhi tugas **Praktikum Pemrograman Web Modul 5**. Fokus utama dari praktikum ini adalah memahami dan mengimplementasikan konsep **Document Object Model (DOM) Manipulation** serta **Event Handling** menggunakan JavaScript murni (Vanilla JS).

Melalui praktikum ini, halaman HTML yang bersifat statis diubah menjadi lebih interaktif dengan merespons aksi pengguna (seperti klik tombol, input teks, dan manipulasi elemen web secara dinamis).

---

## 🛠️ Fitur & Konsep Utama

| Konsep / Fitur | Deskripsi |
| :--- | :--- |
| 🎯 **DOM Selection** | Mengakses dan menangkap elemen HTML menggunakan `document.querySelector()` dan `document.getElementById()`. |
| ⚡ **Event Listener** | Menangani interaksi pengguna seperti event `click`, `submit`, atau `input` menggunakan `addEventListener()`. |
| ✏️ **DOM Modification** | Mengubah teks, atribut, serta class CSS elemen secara dinamis via JavaScript (`textContent`, `innerHTML`, `classList`). |
| ➕ **Dynamic Element Creation** | Membuat dan menambahkan elemen HTML baru ke dalam struktur halaman (`createElement` & `appendChild`). |
